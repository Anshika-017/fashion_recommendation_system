# Fashion Recommendation System

This project implements a content-based fashion recommendation system that suggests visually similar fashion items using deep learning–based image embeddings extracted from a pretrained ResNet-50 model.

## Description

The system learns visual representations of fashion images using a convolutional neural network and recommends similar products based on feature similarity. The workflow is divided into two stages: an offline preprocessing stage where embeddings are generated once, and an online inference stage where recommendations are served through a Streamlit web application.

Images are passed through a pretrained ResNet-50 model (ImageNet weights) with the classification head removed. Global max pooling is applied to obtain a fixed-length feature vector, which is L2-normalized. Recommendations are generated by finding the nearest neighbors in the embedding space using Euclidean distance.

## Model and Methodology

- Backbone CNN: ResNet-50 (pretrained on ImageNet)
- Architecture: ResNet50 (include_top=False) followed by GlobalMaxPooling2D
- Feature representation: 2048-dimensional normalized embedding
- Similarity search: K-Nearest Neighbors (brute-force)
- Distance metric: Euclidean distance

The embedding generation process is computationally expensive and is performed offline only once. The generated embeddings and corresponding image filenames are cached locally and reused during application runtime for fast recommendations.

## Generating Embeddings (Offline Step)

Before running the web application, feature embeddings must be generated once using the dataset images. This is done by running the following command:

python generate_embeddings.py

This script processes all images using ResNet-50 and stores the extracted features locally.

## Running the Streamlit Application

1. Install dependencies:
pip install -r requirements.txt

2. Start the Streamlit web application:
streamlit run main.py

3. Upload a fashion image through the web interface to receive the top-5 visually similar fashion recommendations.

## Note on Large Files

Large embedding files such as embeddings.pkl and filenames.pkl are not included in this repository due to GitHub file size limits. These files are generated locally during the offline preprocessing stage and cached for efficient reuse. This follows standard machine learning engineering best practices.
