# Fashion Recommendation System

This project implements a content-based fashion recommendation system that suggests visually similar fashion items using deep learning–based image embeddings extracted with a pretrained ResNet-50 model.

## Description

The system uses a convolutional neural network to learn visual representations of fashion images and recommends similar products based on feature similarity. The pipeline is designed in two stages: an offline preprocessing stage where image embeddings are generated once, and an online inference stage where recommendations are served through a Streamlit web application.

Each image is passed through a pretrained ResNet-50 model (ImageNet weights) with the classification head removed. Global max pooling is applied to obtain a fixed-length feature vector, which is L2-normalized. Recommendations are generated by finding the nearest neighbors in the embedding space using Euclidean distance.

## Model and Methodology

- Backbone CNN: ResNet-50 (pretrained on ImageNet)
- Architecture: ResNet50 (include_top=False) + GlobalMaxPooling2D
- Feature representation: 2048-dimensional normalized embedding
- Similarity search: K-Nearest Neighbors (brute-force)
- Distance metric: Euclidean distance

The embedding generation process is computationally expensive and is performed offline only once. The generated embeddings and corresponding image filenames are cached locally and reused during application runtime for fast recommendations.

## Web Application

The Streamlit application allows users to upload a fashion image and receive the top-5 visually similar fashion items from the dataset. Upon image upload, the system extracts its embedding using the same ResNet-50 pipeline and performs a nearest-neighbor search against the precomputed embeddings.
